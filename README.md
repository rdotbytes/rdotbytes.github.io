# rdotbytes.github.io

The public website for **rdotbytes** — a landing page and the privacy policy
for every app.

**This is the only public repository.** Every app's source code lives in its
own private repo. Nothing here but web pages.

Google Play requires a privacy policy at a public web address before an app can
be published, which is why this exists. One site serves all of them:

```
/                      the studio page
/<app>/privacy.html    that app's privacy policy
assets/                fonts and app screenshots used by the pages
```

Adding a new app means one folder and one link on the front page.

Served by GitHub Pages from the `main` branch, root folder.
